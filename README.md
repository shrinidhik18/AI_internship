
# AI Internship - Simple Calculator

A beginner-friendly calculator application developed using Python.

## Features

- Addition of two numbers
- Subtraction of two numbers
- User-friendly command-line interface

## Technologies Used

- Python 3
- Git
- GitHub

## Project Structure

```text
AI_internship/
├── src/
│   └── ai_internship/
│       ├── __init__.py
│       └── __main__.py
├── README.md
├── pyproject.toml
└── .gitignore
```

## How to Run

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project:

```bash
cd AI_internship
```

Run the application:

```bash
$env:PYTHONPATH = "src"
python -m ai_internship
```
